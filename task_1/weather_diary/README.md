# Weather diary

Программа анализирует температуры за несколько дней. Сначала она считывает количество дней, затем температуры за каждый день.

Результат состоит из трёх строк:

1. средняя температура с точностью до одного знака;
2. минимальная и максимальная температуры;
3. количество дней с температурой ниже нуля.

Пример ввода:

```text
5
-3 2 5 -1 7
```
