# Work with pointers

Программа демонстрирует работу с динамической памятью, многоуровневыми указателями и `void*`. Она сохраняет изображения разных размеров вместе с метаданными одного из трёх типов:

- обычная камера — фокусное расстояние и выдержка;
- тепловизор — температура окружающей среды;
- спутник — высота и облачность.

Пользователь вводит количество изображений, их тип, метаданные, размеры и значения пикселей. После ввода программа печатает все сохранённые данные и освобождает выделенную память.
