# Money box

Простая консольная копилка. Баланс хранится в целых числах и изначально равен нулю.

Поддерживаемые команды:

- `deposit amount` — пополнить баланс;
- `withdraw amount` — снять деньги;
- `balance` — показать текущий баланс;
- `reset` — обнулить баланс;
- `scholarship` — добавить стипендию в размере 40 000;
- `stop` — завершить программу.

Некорректная команда или операция выводит `error`.
