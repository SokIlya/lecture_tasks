# Display

Консольная модель дисплея размером 10 × 5 символов. Программа позволяет очищать экран, размещать отдельный символ или слово и выводить текущее содержимое.

Поддерживаемые команды:

- `clear` — очистить дисплей;
- `put x y symbol` — поместить символ в координаты `(x, y)`;
- `text x y word` — записать слово, начиная с координат `(x, y)`;
- `print` — вывести дисплей;
- `quit` — завершить программу.

При некорректных координатах или слишком длинном тексте выводится `error`.
